Política de privacidad

Última actualización: 26 de octubre de 2026

Sharys es una herramienta personal usada únicamente por sus dos autores sobre sus propias cuentas. Esta política explica qué datos toca y qué se hace con ellos.

Qué datos se usan

  • YouTube / YouTube Music. Con el permiso https://www.googleapis.com/auth/youtube, que el titular concede de forma expresa, Sharys lee la playlist configurada y agrega o quita canciones en ella. No accede a videos, suscripciones, comentarios ni a ningún otro contenido de la cuenta.
  • Spotify. Con permisos de lectura y edición de playlists, Sharys lee la playlist configurada y agrega o quita canciones en ella.

Los datos tratados son títulos, artistas, duraciones e identificadores de las canciones de esas playlists. Sharys no recopila nombres, correos, ubicación ni ningún dato personal.

Cómo se guardan

  • Las credenciales de acceso (tokens) se guardan cifradas como secretos de GitHub Actions en un repositorio privado del titular. Sharys no las envía a ningún otro lugar.
  • El estado de la sincronización contiene solo identificadores de canciones y se guarda en el mismo repositorio privado.
  • Los registros de ejecución (que incluyen títulos y artistas) quedan en ese repositorio privado, visibles solo para sus dos titulares, y GitHub los conserva según su propia política de retención.

Qué no se hace

  • No se venden, comparten ni transfieren datos a terceros.
  • No hay publicidad, análisis de uso ni cookies de seguimiento.
  • Nadie ajeno a los dos titulares tiene acceso a los datos.

Uso limitado de datos de Google

El uso y la transferencia a cualquier otra aplicación de la información recibida de las API de Google se ajustará a la Política de datos de usuario de los servicios de las API de Google, incluidos los requisitos de uso limitado.

Cómo revocar el acceso

  • Google: myaccount.google.com/permissions → Sharys → Eliminar acceso.
  • Spotify: spotify.com/account/apps → Sharys → Quitar acceso.
  • Para borrar los datos guardados, basta eliminar los secretos y el repositorio privado.

Cambios y contacto

Si esta política cambia, se actualizará la fecha de arriba. Contacto: github.com/Toto829.

Summary in English

Sharys is a personal tool used only by its two authors on their own accounts. It reads and edits one playlist per platform (YouTube Music and Spotify) using permissions each owner grants and can revoke at any time. It handles only track titles, artists and identifiers; it collects no personal data, sells or shares nothing, and has no analytics or ads. Access tokens are stored as encrypted GitHub secrets in a private repository. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Contact: github.com/Toto829.
